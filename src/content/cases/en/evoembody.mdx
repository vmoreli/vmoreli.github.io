## Context and problem

Self-improving agents (such as the Darwin Gödel Machine) usually depend on
large proprietary models. In long embodied tasks they also run into two
problems: the context overflows when reading execution logs, and changes are
validated on the same tasks where the failures were found, which inflates the
result.

## What was built

<PipelineDiagram
  rotulo="One cycle of the evolutionary loop"
  etapas={[
    'Parent agent',
    'Problem Understanding',
    'Solution Proposer',
    'Implementation',
    'Child agent',
    'Validation levels',
  ]}
/>

- **Evolutionary loop:** in each cycle, a parent agent is chosen by
  probability, weighting score, number of children, step efficiency, and
  validation level. A meta-agent expands it into 3 roles:
  1. *Problem Understanding*: reads the failure logs and the code and produces
     a diagnosis;
  2. *Solution Proposer*: proposes a modular change without seeing the traces;
  3. *Implementation*: edits the files and produces the child agent.
- **Context management:** recursive on-demand retrieval, inspired by
  Recursive Language Models. The meta-agent queries chunks of the logs instead
  of receiving them whole, and works with an 8k-token prompt.
- **Disjoint splits:** failures are mined on the training set (3,553 tasks),
  selection happens on validation (140 tasks, in levels of 5/30/60/120/140),
  and the test set (134 out-of-distribution tasks) is evaluated only once, on
  the final agent.
- **Pruning:** a child only moves up a level if it reaches at least 95% of its
  parent's score.
- **Budget:** 50M tokens per run.

## Results

ALFWorld, out-of-distribution test set, 134 tasks.

<ResultsTable rotulo="EvoEmbody: initial and best-agent success on the out-of-distribution test set">

| Meta-agent / task agent | Initial | Best agent | Gain (95% CI) |
|---|---|---|---|
| Qwen3.8-27B / Qwen3.5-4B | 56.0% | **93.3%** | +37.3 pp [29.1; 45.5] |
| Gemma-4-31B / Gemma-4-26B-A4B | 64.9% | **79.1%** | +14.2 pp [5.2; 23.1] |

</ResultsTable>

- Mining failures on training, separate from validation, gives **93.3% versus
  77.6%** when failures and selection come from the same pool. This validates
  the protocol.
- The meta-agents solved real bottlenecks of the agent on their own:
  inventory tracking (validation from 50.0% to 66.7%), state-conditioned
  matching (66.7% to 86.7%), and spatial coordination (70.0% to 83.3%).
